# rehome-frontend

Ngắn gọn module này làm gì trong hệ thống Rehome.

Spring Boot 3.x, PostgreSQL, ...

## Yêu cầu
JDK 17, Maven/Gradle, ...

## Cách chạy
1. Clone repo
2. Config file .env / application.yml
3. mvn spring-boot:run
